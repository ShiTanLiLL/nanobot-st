# nanobot-st

我的个人 AI 助手——基于"项目渐进式复现课程"从零重建的教学项目。

以 [HKUDS/nanobot](https://github.com/HKUDS/nanobot) 为蓝本，不复制其最终架构，
而是从第一个最简单的业务需求开始，随着问题逐渐出现，一步一步重新把它发明出来。

## 状态

课程进行中，进度见 `tutorial/教学大纲.md`。

## 结构

```text
nanobot-st/
├── nanobot_st/    # Python 包（随课程逐课生长）
├── tests/         # pytest 测试
└── tutorial/      # 教程资料：工作守则、教学大纲、教案、参考分析、学习记录
```

## 运行

环境搭建与运行方式见 `tutorial/教案/` 对应课程。
